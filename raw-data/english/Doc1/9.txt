5. If I ______ harder for the test, I would have gotten a better grade.

A. had studied ✅
B. will study
C. did study

Giải thích:

Mệnh đề chính: would have gotten → kết quả giả định trong quá khứ

→ mệnh đề if phải là quá khứ hoàn thành (had + V3)

📌 Công thức chuẩn:
👉 If + had + V3, S + would have + V3

❌ will study / did study → sai loại điều kiện

6. If it hadn't rained, we ______ to the park.

A. will have gone
B. will go
C. would have gone ✅

Giải thích:

If it hadn’t rained → điều kiện quá khứ không có thật

Kết quả cũng là quá khứ giả định

📌 Ghi nhớ:
👉 hadn’t + V3 → would have + V3

❌ will have gone / will go → dùng cho tương lai, sai ngữ cảnh

7. If only we ______ the directions!

A. will follow
B. did follow
C. had followed ✅

Giải thích:

If only diễn tả sự hối tiếc

Hối tiếc về việc đã không làm trong quá khứ → dùng had + V3

📌 Cấu trúc cực hay ra thi:
👉 If only + had + V3 = Giá như… (quá khứ)

❌ will follow / did follow → không diễn tả hối tiếc quá khứ
