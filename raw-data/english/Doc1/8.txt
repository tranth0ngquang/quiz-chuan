1. If I hadn't overslept, I ______ on time.

A. will have been
B. would have been ✅
C. will be

Giải thích:

Mệnh đề if: If I hadn’t overslept → quá khứ hoàn thành

Kết quả nói về một việc KHÔNG xảy ra trong quá khứ
→ dùng would have + V3

📌 Công thức chuẩn:
👉 If + had + V3, S + would have + V3

❌ will have been / will be → sai thì, sai loại điều kiện

2. If you had eaten a good breakfast, you ______ so hungry now.

A. wouldn't be ✅
B. can't be
C. won't be

Giải thích:

Mệnh đề if: quá khứ (had eaten)

Kết quả ảnh hưởng đến hiện tại (now)
→ Câu điều kiện hỗn hợp

📌 Công thức:
👉 If + had + V3, S + would (not) + V (hiện tại)

❌ can't be / won't be → không phải câu điều kiện giả định

3. I ______ that car if I had had more money at the time.

A. could have bought ✅
B. could buy
C. will buy

Giải thích:

at the time → quá khứ

Điều kiện không có thật trong quá khứ → kết quả cũng là quá khứ giả định

could have + V3 = đã có thể làm nhưng không làm

📌 Bẫy TOEIC:
👉 If + had had → could/would have + V3

❌ could buy / will buy → sai thì

4. That horse could have won the race if he ______ hurt his leg.

A. doesn't hurt
B. hasn't hurt
C. hadn't hurt ✅

Giải thích:

could have won → kết quả quá khứ giả định

Mệnh đề if → hadn't + V3

📌 Cấu trúc chuẩn:
👉 S + could have + V3 if + hadn't + V3

❌ doesn't hurt / hasn't hurt → sai thì

🔥 Tóm tắt nhanh để đi thi TOEIC (rất quan trọng)
🔹 Điều kiện loại 3 (quá khứ – quá khứ)

If + had + V3, S + would/could have + V3

🔹 Điều kiện hỗn hợp (quá khứ → hiện tại)

If + had + V3, S + would + V
